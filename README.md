# Desafio 01: Criando sua primeira Landing Page com HTML e CSS

Esta landing page foi criada com base no desafio proposto na [DIO.me](https://dio.me). Os commit iniciais foram feitos com títulos e descrições fora do padrão, mas os novos estão sendo nomeados conforme vou aprendendo mais sobre as formas mais usuais de fazê-lo. 

O design completo foi finalizado no dia 06/08/2026, mas se trata da versõ inicial apenas funcional, mas ainda apresentando alguns desvios de estilização que não afetam a navegação ou experiência de forma significativa. 

Os próximos passos serão acertar pequenos detalhes visuais, depois ajustar a responsividade da página ao redimensionamento e por último, tornar o código mais limpo.
